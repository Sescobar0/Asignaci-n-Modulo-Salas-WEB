para iniciar el Backend hay que tener instalado el XAMP para la base de datos local, desde la terminal nos ubicamos en la carpeta Backend con "Cd Backend" y activamos con "Nodemon server.js"

Para abrir el Fronend se habre una termial, nos ubicamos en la carpeta Fronent con "Cd Frontend" y damos el comando "npm run dev" e ingresamos al link del local host que nos arroja.
